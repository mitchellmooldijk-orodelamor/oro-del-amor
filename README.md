# Oro Del Amor Pomeranians

Wij willen gaan een website maken voor onze kennel voor pomerianen. Onze kennel gaat Corazón de Oro heten en moet een professionele uitstraling hebben. De basis kleuren zijn zwart en goud en vleugje beige erin. Ik heb afbeeldingen als voorbeeld van onze uitstraling. zou je een mooi website design willen maken die passend is bij onze kennel en doel hiervan
